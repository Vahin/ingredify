# Design Source

The main design file is:

`designs/ingredify-app-design.pen`

Use the `Ingredify Design System v1` frame as the source of truth for colors, typography, spacing, radius, shadows, components, and page layout conventions.

When creating or editing Ingredify UI, inspect this file first. Design assets are located in:

- `designs/images/`
- `designs/icons/`
- `designs/references/`
