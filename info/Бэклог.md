# Бэклог Ingredify

## MVP

### Авторизация и пользователи

- [ ] Регистрация пользователя по email и паролю
- [ ] Вход пользователя по email и паролю
- [ ] Выход из аккаунта
- [ ] Хранение пользовательских сессий в Redis
- [ ] Хеширование паролей перед сохранением
- [ ] Защита приватных страниц от неавторизованных пользователей
- [ ] Страница профиля пользователя
- [ ] Отображение профильных данных: email, имя, дата создания аккаунта

### Рецепты

- [ ] Страница пользователя со списком его рецептов
- [ ] Страница просмотра приватного рецепта
- [ ] Создание рецепта
- [ ] Редактирование рецепта
- [ ] Физическое удаление рецепта из БД
- [ ] Проверка, что пользователь может видеть и менять только свои рецепты

### Поля рецепта

- [ ] Название рецепта
- [ ] Описание рецепта
- [ ] Изображение рецепта как URL или пустое поле без загрузки файлов
- [ ] Структурированный список ингредиентов
- [ ] Количество ингредиента
- [ ] Единица измерения ингредиента
- [ ] Пошаговое описание приготовления

### Интерфейс

- [ ] Страница регистрации
- [ ] Страница входа
- [ ] Страница профиля
- [ ] Страница списка рецептов пользователя
- [ ] Страница просмотра рецепта
- [ ] Форма создания рецепта
- [ ] Форма редактирования рецепта
- [ ] Подтверждение удаления рецепта
