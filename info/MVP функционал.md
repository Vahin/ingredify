# MVP функционал

## Цель MVP

Собрать минимальную рабочую версию Ingredify, в которой пользователь может зарегистрироваться, войти в аккаунт и вести приватную базу своих рецептов.

MVP должен быть простым: без публичных рецептов, поиска, подписок, планировщика питания, списка покупок, загрузки файлов и социальных функций.

## Пользователи и авторизация

### Регистрация

Пользователь может создать аккаунт по email и паролю.

Минимальные поля пользователя:

- email
- пароль в виде хеша
- имя
- дата создания аккаунта

### Вход

Пользователь входит по email и паролю.

После успешного входа создается пользовательская сессия. Сессии хранятся в Redis.

### Выход

Пользователь может выйти из аккаунта. При выходе активная сессия удаляется из Redis.

## Профиль пользователя

У авторизованного пользователя есть страница профиля.

На странице отображаются:

- имя
- email
- дата создания аккаунта
- список рецептов пользователя или ссылка на список рецептов

## Рецепты

Все рецепты в MVP приватные. Пользователь видит только свои рецепты.

### Список рецептов

На странице пользователя отображается список всех его рецептов.

В списке достаточно показывать:

- название рецепта
- краткое описание
- изображение, если указано
- ссылку на просмотр
- действия редактирования и удаления

### Просмотр рецепта

Страница рецепта показывает полную информацию:

- название
- описание
- изображение, если указано
- ингредиенты с количеством и единицей измерения
- шаги приготовления

### Создание рецепта

Пользователь может создать рецепт.

Минимальные поля рецепта:

- название
- описание
- изображение как URL или пустое поле
- ингредиенты
- шаги приготовления

Загрузка изображений в MVP не нужна.

### Редактирование рецепта

Пользователь может редактировать только свои рецепты.

Редактируются те же поля, что используются при создании рецепта.

### Удаление рецепта

Пользователь может удалить свой рецепт.

Удаление физическое: запись рецепта и связанные данные удаляются из БД.

## Ингредиенты

Ингредиенты хранятся структурированно.

Минимальные поля ингредиента:

- название
- количество
- единица измерения
- порядок отображения

## Шаги приготовления

Шаги приготовления хранятся структурированно.

Минимальные поля шага:

- текст шага
- порядок отображения

## Ограничения MVP

В MVP не входит:

- публичный доступ к рецептам
- доступ по ссылке
- загрузка изображений
- поиск и фильтрация
- категории и теги
- избранное
- список покупок
- планировщик питания
- импорт рецептов по URL
- расчет КБЖУ
- бюджетирование
- социальные функции
