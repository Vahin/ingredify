# Пользовательские сценарии Ingredify

## Персоны пользователей

#### 1. Начинающий кулинар

**Демография:** 22 года, студент, живёт один

**Цели:**
- Научиться готовить простые блюда
- Сохранять понравившиеся рецепты
- Искать рецепты, в которых сложно сделать ошибку

**Боли:**
- Неопытен, нужны четкие инструкции в рецептах
- Вероятно, ограничен в бюджете
- Возможно, нет необходимых приспособлений на кухне
- Сложно ориентироваться в рецептах и находить простые

---

#### 2. Повар-любитель

**Демография:** 30 лет, офисный работник, живёт с семьёй

**Цели:**
- Готовить интересные блюда по выходным
- Радовать семью новыми вкусами
- Коллекционировать проверенные рецепты

**Боли:**
- Мало времени на готовку в будни
- Сложно найти действительно интересные рецепты
- Хочется разнообразия, но нет времени на эксперименты

---

#### 3. Вынужденный повар

**Демография:** 35 лет, родитель троих детей, работает неполный день

**Цели:**
- Быстро готовить сытные блюда для семьи
- Планировать меню на неделю вперёд
- Минимизировать время на кухне

**Боли:**
- Дети разборчивы в еде
- Нужно готовить каждый день
- Усталость от рутины «что приготовить сегодня»
- Ограниченный бюджет на продукты

---

#### 4. Повар-диетолог

**Демография:** 28 лет, фитнес-тренер, следит за здоровьем

**Цели:**
- Контролировать КБЖУ каждого блюда
- Подбирать рецепты под свои нормы
- Вести учёт пищевых привычек

**Боли:**
- Сложно найти рецепты с точным расчётом калорий
- Мало вариантов для специфических диет (кето, палео, веган)
- Нужно адаптировать рецепты под свои требования

---

#### 5. Повар-профессионал

**Демография:** 40 лет, шеф-повар, работает в ресторане

**Цели:**
- Коллекционировать авторские рецепты
- Экспериментировать с сочетаниями вкусов
- Делиться профессиональными техниками

**Боли:**
- Сложно структурировать свои наработки
- Мало платформ для профессионального обмена опытом
- Хочется фиксировать нюансы приготовления

---

#### 6. Повар-эконом

**Демография:** 45 лет, пенсионерка, живёт с супругом

**Цели:**
- Готовить из доступных продуктов
- Использовать остатки из холодильника
- Планировать бюджет на еду

**Боли:**
- Ограниченный бюджет
- Жалко выбрасывать продукты
- Сложно придумать блюдо из того, что есть

---

#### 7. Повар-блогер

**Демография:** 25 лет, ведёт кулинарный блог в соцсетях

**Цели:**
- Красиво оформлять рецепты для публикации
- Быстро делиться рецептами с аудиторией
- Собирать статистику популярных блюд

**Боли:**
- Нужно тратить время на оформление
- Сложно вести учёт рецептов в разных форматах
- Хочется автоматизировать публикацию

---

#### 8. Кафе / Ресторан

**Демография:** Владелец небольшого кафе

**Цели:**
- Вести базу технологических карт
- Контролировать себестоимость блюд
- Обучать новых поваров

**Боли:**
- Сложно стандартизировать рецепты
- Высокая текучка кадров
- Нужно быстро масштабировать меню

## Основные пользовательские сценарии (MVP)

### Сценарий 1: Регистрация
**Актёр:** Незарегистрированный пользователь

**Предусловие:** Пользователь зашёл на сайт

**Шаги:**
1. Пользователь нажимает «Зарегистрироваться»
2. Вводит email, пароль, имя
3. Система создаёт учётную запись
4. Пользователь автоматически авторизуется

**Результат:** Учётная запись создана, пользователь авторизован

---

### Сценарий 2: Авторизация
**Актёр:** Зарегистрированный пользователь

**Предусловие:** Пользователь имеет учётную запись

**Шаги:**
1. Пользователь нажимает «Войти»
2. Вводит email и пароль
3. Система проверяет данные
4. Пользователь попадает в личный кабинет

**Результат:** Пользователь авторизован

---

### Сценарий 3: Создание рецепта
**Актёр:** Зарегистрированный пользователь

**Предусловие:** Пользователь авторизован

**Шаги:**
1. Пользователь нажимает «Добавить рецепт»
2. Заполняет поля:
   - Название блюда
   - Описание
   - Ингредиенты (название + количество + единица измерения)
   - Пошаговая инструкция приготовления
   - Фото (опционально)
3. Сохраняет рецепт

**Результат:** Рецепт сохранён в личной базе пользователя

---

### Сценарий 4: Редактирование рецепта
**Актёр:** Зарегистрированный пользователь

**Предусловие:** У пользователя есть сохранённые рецепты

**Шаги:**
1. Пользователь открывает свой рецепт
2. Видит полную информацию (ингредиенты, шаги, фото)
3. Нажимает «Редактировать»
4. Вносит изменения
5. Сохраняет

**Результат:** Рецепт обновлён

---

### Сценарий 5: Удаление рецепта
**Актёр:** Зарегистрированный пользователь

**Предусловие:** У пользователя есть сохранённые рецепты

**Шаги:**
1. Пользователь открывает рецепт
2. Нажимает «Удалить»
3. Подтверждает удаление

**Результат:** Рецепт удалён из базы

---

### Сценарий 6: Просмотр рецепта по прямой ссылке
**Актёр:** Любой пользователь (авторизованный или нет)

**Предусловие:** Существует рецепт с публичной ссылкой

**Шаги:**
1. Пользователь переходит по прямой ссылке на рецепт
2. Система открывает страницу рецепта (только просмотр)

**Результат:** Пользователь видит рецепт

---

### Сценарий 7: Поделиться рецептом
**Актёр:** Зарегистрированный пользователь

**Предусловие:** У пользователя есть сохранённый рецепт

**Шаги:**
1. Пользователь открывает свой рецепт
2. Нажимает «Поделиться»
3. Система генерирует/копирует прямую ссылку
4. Пользователь отправляет ссылку другому человеку

**Результат:** Ссылка на рецепт скопирована/отправлена

---

## Сценарии для будущих версий (Post-MVP)

### Сценарий 8: Добавление рецепта в избранное
**Актёр:** Зарегистрированный пользователь

**Предусловие:** Пользователь просматривает ленту рецептов

**Шаги:**
1. Пользователь видит рецепт в ленте
2. Нажимает иконку «сердечка»
3. Рецепт добавляется в раздел «Избранное»

**Результат:** Рецепт помечен как избранный для быстрого доступа

---

### Сценарий 9: Поиск рецепта по ингредиентам
**Актёр:** Зарегистрированный пользователь

**Предусловие:** У пользователя есть сохранённые рецепты

**Шаги:**
1. Пользователь открывает поиск
2. Вводит ингредиенты, которые есть в холодильнике (например, «курица, рис, сыр»)
3. Система показывает рецепты, содержащие эти ингредиенты
4. Пользователь выбирает рецепт

**Результат:** Найден подходящий рецепт из имеющихся продуктов

---

### Сценарий 10: Фильтрация рецептов по категории
**Актёр:** Зарегистрированный пользователь

**Предусловие:** У пользователя есть сохранённые рецепты

**Шаги:**
1. Пользователь открывает страницу рецептов
2. Выбирает фильтр (например, «Завтраки» или «Веганское»)
3. Система показывает отфильтрованные рецепты

**Результат:** Пользователь видит только релевантные рецепты

---

### Сценарий 11: Генерация списка покупок
**Актёр:** Зарегистрированный пользователь

**Шаги:**
1. Пользователь выбирает рецепты на неделю
2. Нажимает «Сформировать список покупок»
3. Система агрегирует ингредиенты, объединяет одинаковые
4. Пользователь получает готовый список

---

### Сценарий 12: Планировщик питания на неделю

**Шаги:**

2. Перетаскивает рецепты на дни недели
3. Система автоматически формирует список покупок
