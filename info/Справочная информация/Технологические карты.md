
**Технологическая карта (ТК)** — основной документ в общественном питании, описывающий технологию приготовления блюда и требования к его качеству.

## Структура техкарты

| Раздел                       | Описание                                          |
| ---------------------------- | ------------------------------------------------- |
| **Наименование блюда**       | Точное название по меню                           |
| **Перечень сырья**           | Все ингредиенты с нормами закладки (брутто/нетто) |
| **Технология приготовления** | Пошаговое описание процесса                       |
| **Требования к качеству**    | Внешний вид, вкус, цвет, запах, консистенция      |
| **Пищевая ценность**         | Калорийность, Б/Ж/У на порцию                     |
| **Срок годности**            | Условия и время хранения                          |
| **Выход**                    | Вес готового блюда                                |

## Назначение в кафе и ресторанах

1. **Стандартизация** — одно и то же блюдо будет одинаковым независимо от повара
2. **Калькуляция себестоимости** — точный расчёт затрат на каждое блюдо
3. **Контроль качества** — чёткие критерии, каким должно быть блюдо
4. **Обучение персонала** — новый повар быстро освоит рецептуру
5. **Требования надзорных органов** — обязательный документ по ГОСТ/ТР ТС
6. **Расчёт порций** — правильные закладки без «работы на глаз»

## Пример

Для борща техкарта укажет:
- точный вес свёклы, капусты, мяса
- последовательность закладки овощей
- время варки
- температуру подачи
- срок хранения (например, 2 часа при 65–75°C)

> [!IMPORTANT]
> Без техкарт в ресторане начинается хаос: разные порции, нестабильный вкус, невозможность контролировать фудкост.
