# Дизайн

Источник истины — проект **Ingredify** в [Open Design](http://127.0.0.1:17573/project/ingredify).

Запуск Open Design из корня репозитория:

```bash
npm run design
```

Синхронизация HTML-артефактов из `designs/` в Open Design:

```bash
node scripts/sync-design-to-open-design.mjs
```

Скрипт также загружает изображения из `public/recipes/` и `public/ingredients/`, а SVG КБЖУ — из `src/widgets/recipe-intro/assets/icons/` для `recipe-page.html`.

## Артефакты в `designs/`

| Файл | Назначение |
|------|------------|
| `DESIGN.md` | Токены и правила дизайн-системы v1 |
| `shared-tokens.css` | Общие CSS-токены и классы для HTML-артефактов |
| `recipe-page.html` | Страница рецепта (основной экран) |
| `cart-page.html` | Экран корзины с табами, заполненным и пустым состоянием |
| `design-system.html` | Палитра, типографика, компоненты |
| `login-page.html` | Экран входа |

Токены синхронизированы с `src/app/globals.css`. При изменении UI обновляйте артефакты и повторно запускайте скрипт синхронизации.

При создании новых страниц ориентируйтесь на `design-system.html` и `DESIGN.md` для цветов, типографики, отступов, скруглений, теней и компонентов.
