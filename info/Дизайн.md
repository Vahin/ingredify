# Дизайн

Основной файл дизайна приложения:

`designs/ingredify-app-design.pen`

Содержит:
- экран страницы рецепта;
- `Ingredify Design System v1`;
- визуальные правила и примеры базовых компонентов.

Дизайн-ассеты:
- изображения: `designs/images/`
- иконки: `designs/icons/`
- референсы: `designs/references/`

При создании новых страниц использовать frame `Ingredify Design System v1` в `designs/ingredify-app-design.pen` как визуальный источник истины для цветов, типографики, отступов, скруглений, теней и компонентов.
