# EquipmentCard

## Описание

`EquipmentCard` отображает список инвентаря, необходимого для рецепта. Компонент принимает `recipe`.

## Поведение

Компонент строит секцию `Инвентарь` из массива `recipe.equipment`. Секция связана с заголовком через `aria-labelledby`, а элементы выводятся обычным списком `ul`.
