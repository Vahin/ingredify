# IngredientsCard

## Описание

`IngredientsCard` отображает список ингредиентов рецепта. Компонент принимает `recipe`.

## Поведение

Компонент выводит заголовок `Ингредиенты`, визуальный переключатель количества порций и список `recipe.ingredients`. Каждый ингредиент показывает состояние отметки, название и количество; отмеченные элементы подсвечиваются акцентным стилем.
