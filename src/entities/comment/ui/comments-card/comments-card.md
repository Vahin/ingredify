# CommentsCard

## Описание

`CommentsCard` отображает карточку комментариев рецепта. Компонент принимает `recipe`.

## Поведение

Компонент выводит список комментариев из `recipe.comments`, инициалы автора, имя, опциональную метку и текст комментария. Внизу находится визуальная форма добавления нового комментария с полем ввода и кнопкой отправки, но отправка пока не подключена к данным.
