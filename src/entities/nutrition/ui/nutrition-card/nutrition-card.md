# NutritionCard

## Описание

`NutritionCard` отображает один показатель пищевой ценности рецепта. Компонент принимает `variant` и числовое значение `stat`.

## Поведение

Для калорий значение выводится как число, для белков, жиров и углеводов добавляется единица `г`. Название показателя берётся из локального словаря, а иконка рендерится через `NutritionIcon`.
