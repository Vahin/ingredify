# NutritionStats

## Описание

`NutritionStats` отображает сетку пищевой ценности рецепта. Компонент принимает объект `nutrition` с калориями, белками, жирами и углеводами.

## Поведение

Для каждого показателя рендерится `NutritionCard`; сетка адаптируется от одной колонки до четырёх колонок на широких экранах.
