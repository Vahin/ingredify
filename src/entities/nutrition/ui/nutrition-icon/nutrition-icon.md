# NutritionIcon

## Описание

`NutritionIcon` отображает иконку для одного показателя пищевой ценности. Компонент принимает `variant` типа `NutritionVariant`.

## Поведение

Компонент выбирает соответствующий SVG-ассет и цвет по `variant`. Рендер выполняется через общий компонент `Icon`, а контейнер задаёт круглый фон и фиксированный размер.
