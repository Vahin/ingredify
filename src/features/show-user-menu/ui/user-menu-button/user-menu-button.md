# UserMenuButton

## Описание

`UserMenuButton` отображает кнопку перехода в профиль текущего пользователя. Компонент принимает `user`.

## Поведение

Компонент строит инициалы через `getInitials` и рендерит ссылку на `/profile`. Визуально это круглая акцентная кнопка с `aria-label='Открыть профиль'`.
