# Search

## Описание

`Search` отображает поле поиска рецептов, ингредиентов или кухни. Компонент включает скрытую подпись для доступности, иконку поиска из `lucide-react` и `input` с типом `search`.

## Поведение

Поле занимает всю ширину на мобильной раскладке и возвращается в обычную позицию на `md`-экранах. Визуальное состояние фокуса задаётся Tailwind-классами через фон и outline.
