# LogoutButton

## Описание

`LogoutButton` отображает кнопку выхода из аккаунта.

## Поведение

Компонент отправляет форму на server action `logout`, передаёт скрытое поле `next` для маршрута возврата после выхода и использует общий `Button`. Через пропсы можно настроить `className`, `variant`, `size` и значение `next`.
