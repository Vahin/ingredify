# LoginForm

## Описание

`LoginForm` отображает клиентскую форму входа в аккаунт.

## Поведение

Компонент использует `useActionState` с server action `login`, поддерживает скрытое поле `next` для возврата после входа и показывает общую ошибку формы при наличии `state.errors.form`. Поля email и пароля рендерятся через `AuthField`, кнопка блокируется на время отправки, а внизу есть ссылка на регистрацию.
