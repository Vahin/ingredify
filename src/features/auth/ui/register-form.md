# RegisterForm

## Описание

`RegisterForm` отображает клиентскую форму создания аккаунта.

## Поведение

Компонент использует `useActionState` с server action `register`, выводит поля имени, email и пароля через `AuthField`, блокирует кнопку отправки во время выполнения и меняет текст кнопки на состояние регистрации. Внизу есть ссылка на страницу входа `/login`.
