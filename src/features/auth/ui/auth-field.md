# AuthField

## Описание

`AuthField` отображает подписанное поле ввода для форм авторизации и регистрации.

## Поведение

Компонент принимает `id`, `label`, `name`, опциональные `type`, `autoComplete` и список ошибок. При наличии ошибок выставляет `aria-invalid`, подсвечивает поле destructive-стилем и показывает первое сообщение об ошибке под инпутом.
