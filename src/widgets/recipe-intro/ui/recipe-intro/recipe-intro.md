# RecipeIntro

## Описание

`RecipeIntro` отображает верхний блок карточки рецепта. Компонент принимает `recipe`.

## Поведение

Компонент считает количество комментариев и собирает hero-блок из изображения, автора, заголовка с описанием, пищевой ценности и кнопок действий. Секция связана с заголовком рецепта через `aria-labelledby='recipe-title'`.
