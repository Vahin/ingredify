# RecipeActions

## Описание

`RecipeActions` отображает кнопки действий для рецепта. Компонент принимает `commentsCount`.

## Поведение

Компонент показывает кнопки сохранения, перехода или фокуса на комментарии и лайка. Визуально используются иконки `IconOld`; интерактивное состояние сохранения и лайка пока не связано с данными.
