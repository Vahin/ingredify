# RecipeAuthor

## Описание

`RecipeAuthor` отображает автора рецепта. Компонент принимает `author`, подпись роли фиксирована: «Автор рецепта».

## Поведение

Компонент показывает круглый аватар-заглушку с инициалами `АК`, имя автора и подпись роли. Используется внутри верхнего блока рецепта.
