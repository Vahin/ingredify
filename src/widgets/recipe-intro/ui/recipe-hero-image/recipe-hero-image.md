# RecipeHeroImage

## Описание

`RecipeHeroImage` отображает главное изображение рецепта. Компонент принимает URL изображения через `image`.

## Поведение

Компонент рендерит изображение с помощью `next/image` в адаптивном контейнере с фиксированным соотношением сторон. Изображение помечено как `priority`, потому что находится в верхнем видимом блоке рецепта.
