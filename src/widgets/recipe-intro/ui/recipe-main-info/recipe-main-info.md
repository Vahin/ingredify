# RecipeMainInfo

## Описание

`RecipeMainInfo` отображает основную текстовую информацию о рецепте: заголовок и описание.

## Поведение

Компонент принимает `title` и `description`. Заголовок получает `id='recipe-title'`, чтобы родительские секции могли ссылаться на него через `aria-labelledby`. Стили задают крупный адаптивный заголовок и ограниченную ширину описания для удобного чтения.
