# HeaderAuthActions

## Описание

`HeaderAuthActions` отображает действия авторизации в шапке.

## Поведение

Компонент получает текущего пользователя через `getCurrentUser`, текущий путь через `getCurrentPathname` и строит ссылку входа с помощью `buildLoginHref`. Для авторизованного пользователя показывается `UserMenuButton`; для гостя отображаются кнопки входа и регистрации.
