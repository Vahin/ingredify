# Header

## Описание

`Header` отображает верхнюю навигационную панель приложения.

## Поведение

Компонент собирает `Logo`, `Search` и `HeaderAuthActions` внутри sticky-шапки. Раскладка адаптируется от двух колонок на мобильных экранах до трёх колонок на `md`-экранах.
