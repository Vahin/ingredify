# CookingStep

## Описание

`CookingStep` отображает список шагов приготовления рецепта. Компонент принимает `recipe`.

## Поведение

Компонент строит секцию `Шаги приготовления` из `recipe.steps`. Каждый шаг получает порядковый номер, текст и, если доступно, изображение через `next/image` с адаптивными размерами. Секция связана с заголовком через `aria-labelledby`.
