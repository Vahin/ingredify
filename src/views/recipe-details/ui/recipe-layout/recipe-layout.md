# RecipeLayout

## Описание

`RecipeLayout` задаёт двухколоночную раскладку страницы рецепта. Компонент принимает `content` и `sidebar` как `React.ReactNode`.

## Поведение

Основная колонка содержит контент рецепта, а сайдбар предназначен для ингредиентов и инвентаря, имеет `aria-label` и становится sticky на широких экранах.
