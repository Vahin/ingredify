# RecipeDetailsContent

## Описание

`RecipeDetailsContent` собирает основной контент страницы рецепта. Компонент принимает `recipe`.

## Поведение

Компонент последовательно рендерит интро рецепта, шаги приготовления и карточку комментариев. Он не содержит собственной логики отображения данных, а связывает виджеты и сущности в центральной колонке страницы.
