# IconOld

## Описание

`IconOld` рендерит встроенные SVG-иконки по имени.

## Поведение

Компонент принимает `name` из фиксированного набора `bookmark`, `check`, `heart`, `message`, `minus`, `plus`, `search`, `send` и опциональный `className`. SVG скрыт от accessibility tree через `aria-hidden`, а внешний размер и цвет задаются классами родителя или переданным `className`.
