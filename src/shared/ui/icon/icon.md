# Icon

## Описание

`Icon` рендерит SVG-компонент, переданный через проп `SVG`.

## Поведение

Компонент используется как общий адаптер для импортированных SVG-ассетов. Он прокидывает `className` и остальные SVG-пропсы в переданный компонент, а также скрывает иконку от accessibility tree через `aria-hidden`.
