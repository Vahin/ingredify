# Logo

## Описание

`Logo` отображает бренд Ingredify в шапке или других местах интерфейса. Компонент состоит из текстового логотипа и квадратного акцентного знака с буквой `i`.

## Поведение

Логотип является ссылкой на главную страницу `/` через `next/link`. Стили задаются Tailwind-классами: компонент сохраняет компактную ширину, выравнивает элементы по центру и адаптирует размер текста на `md`-экранах.
