# Button

## Описание

`Button` является общим UI-компонентом кнопки.

## Поведение

Компонент использует `class-variance-authority` для вариантов `default`, `outline`, `secondary`, `ghost`, `destructive`, `link` и размеров от `xs` до icon-вариантов. При `asChild` кнопка рендерится через `Slot.Root`, что позволяет применять стили кнопки к ссылкам и другим интерактивным элементам.

`buttonVariants` экспортируется отдельно для повторного использования классов кнопки вне компонента.
