# Ingredify Design System v1

Восстановлено из текущей реализации (`src/app/globals.css` и UI-компонентов).

## Цвета

| Токен | Значение | Использование |
|-------|----------|---------------|
| `--background` | `#f9fafb` | Фон страницы |
| `--foreground` | `#111827` | Основной текст |
| `--card` | `#ffffff` | Карточки, шапка |
| `--muted` | `#f3f4f6` | Вторичные фоны, поля ввода |
| `--border` | `#e5e7eb` | Границы |
| `--accent` | `#22c55e` | CTA, акценты, логотип |
| `--accent-hover` | `#16a34a` | Hover CTA |
| `--secondary` | `#6b7280` | Вторичный текст |
| `--error` | `#ef4444` | Ошибки |

## Типографика

- Шрифт: Inter / Geist (`font-sans`)
- Заголовок рецепта: `clamp(30px, 4vw, 38px)`, weight 850
- Заголовки секций: 22–24px, weight 850
- Основной текст: 15px, line-height 1.6
- Мелкий текст: 12–13px

## Скругления и тени

- Карточки: `border-radius: 16px` (`rounded-2xl`)
- Кнопки действий: `10px`
- Тень карточки: `0 12px 34px` с 10% foreground
- Тень шага: `0 6px 20px` с 8% foreground

## Макет

- Контейнер: `max-width: 1200px`
- Страница рецепта: 2 колонки на `lg` — контент + сайдбар 296px
- Отступы: `px-4` / `px-6`, вертикальные `gap` 18–22px

## Артефакты

- `recipe-page.html` — страница рецепта (демо: вишневый коблер)
- `design-system.html` — базовые компоненты
- `login-page.html` — экран входа
