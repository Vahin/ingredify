# Ingredify Design System v1

Синхронизировано с `src/app/globals.css` и UI-компонентами Next.js.

## Цвета

| Токен | Значение | Использование |
|-------|----------|---------------|
| `--background` | `#f9fafb` | Фон страницы |
| `--foreground` | `#111827` | Основной текст |
| `--card` | `#ffffff` | Карточки, шапка |
| `--muted` | `#f3f4f6` | Вторичные фоны, pill-поля |
| `--border` | `#e5e7eb` | Границы |
| `--accent` | `#22c55e` | Логотип, CTA рецепта, ссылки auth |
| `--accent-hover` | `#16a34a` | Hover accent-кнопок |
| `--primary` | `#171717` | shadcn default (вход, регистрация в шапке) |
| `--secondary` | `#6b7280` | Вторичный текст |
| `--destructive` | `#ef4444` | Ошибки |

## Типографика

- Шрифт: **Geist** (`font-sans` в приложении)
- Заголовок рецепта: `clamp(30px, 4vw, 38px)`, weight 850
- Заголовки секций: 22–24px, weight 850
- Основной текст: 15px, line-height 1.6
- Мелкий текст: 10–13px

## Скругления и тени

- Карточки: `16px` (`rounded-2xl`)
- Фото рецепта: `14px`
- Кнопки действий рецепта: `10px`
- shadcn-кнопки в шапке: `8px` (`rounded-lg`)
- Тень карточки: `0 12px 34px` с 10% foreground

## Макет

- Контейнер: `max-width: 1200px`
- Шапка: на мобиле поиск на всю ширину под логотипом и действиями
- Страница рецепта: на `lg` — контент + сайдбар 296px; на `md` сайдбар в две колонки
- Корзина: контейнер `max-width: 640px`, табы `36px` на `--muted`, строки `32px minmax(0,1fr) auto`
- Отступы: `px-4` / `px-6`, вертикальные `gap` 18–22px

## Изображения

В `recipe-page.html` используются те же относительные пути, что в приложении (`recipes/…`, `ingredients/…` из `public/`, SVG КБЖУ из `src/widgets/recipe-intro/assets/icons/`). Скрипт синхронизации копирует их в проект Open Design рядом с HTML.

## Ингредиент лайн

Строка ингредиента в приложении — **вариант 03** (карточка с левой полосой): `grid-cols-[32px_minmax(0,1fr)_auto]`, `gap-2`, `py-1.5 px-2`, граница, лёгкая тень, полоса `--accent-hover` в корзине, стикер без обводки. На hover/focus стикер уступает место icon-only кнопке добавления или удаления.

## Корзина

- Ссылка корзины в шапке — круглая `38px`, border `--border`, бейдж `18px` на `--accent`.
- Страница корзины использует табы `По рецептам` / `Общий список`; активный таб — `--background` с лёгкой тенью.
- Строка корзины повторяет компактный ингредиент-ряд: стикер 32px, название, моноширинное количество и ghost-кнопка `Удалить`.
- Пустое состояние — одиночная карточка `rounded-2xl` с текстом по центру.

## Артефакты

- `shared-tokens.css` — общие токены и классы кнопок/полей
- `recipe-page.html` — страница рецепта (демо: вишневый коблер из seed)
- `cart-page.html` — страница корзины с заполненным и пустым состоянием
- `design-system.html` — палитра, типографика, компоненты
- `login-page.html` — экран входа
- `ingredient-line-variants.html` — 4 варианта «Ингредиент лайн» в токенах проекта (на основе пилюли и карточки с полосой)

После правок: `node scripts/sync-design-to-open-design.mjs`
